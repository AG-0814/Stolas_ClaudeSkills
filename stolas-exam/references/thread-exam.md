# thread 教材的題型與出題

SKILL.md 判定為 thread 模式時，出題前讀取。

## 兩種驗收

| | 期中驗收 | 最終驗收 |
|---|---|---|
| 範圍 | 上次驗收後新講解 (或已寫教材) 的節點 | 全部節點 (含已寫教材)，加上先前未通過的補測題 |
| 題數 | 2 到 3 題 | 3 到 5 題 |
| 題型 | 至少兩種 | 至少兩種 (經典文本至少三種) |
| 已掌握的節點 | 不考 | 可用綜合題輕度帶過 |

「跳至結尾驗收」時，尚未講解的節點直接出題。使用者答得出來，代表他原本就會，節點狀態直接標為「已掌握」；答不出來的，在補強時講解，並在教材補上對應小節 (見 SKILL.md 步驟 5)。

## 術語單元的題型

| 題型 | 考什麼 | 範例 (不飽和脂肪) |
|---|---|---|
| 解釋題 | 能否用白話說清楚機制 | 用你自己的話說明，為什麼橄欖油在常溫是液體、豬油是固體。 |
| 應用題 | 能否套用到沒講過的新情境 | 椰子油是植物油，常溫卻多半是固體，推測它的脂肪酸組成。 |
| 辨析題 | 能否分辨相近概念或指出錯誤說法 | 有人說「不飽和脂肪就是沒吃飽的脂肪」，錯在哪裡。 |

**回扣起點問題**：教材有「起點問題」章節 (由觀察查核開啟的單元) 時，最終驗收至少一題回扣使用者的原始觀察 (應用題形式)，例如「用獨占性競爭解釋你一開始觀察到的現象：為什麼飲料店小品牌多，速食業卻由少數大品牌主導」。這題能確認使用者把術語接回了自己的問題。

## 經典文本單元的題型

教材 frontmatter 的類型標籤為 `類型/經典文本` (或教材使用文本地圖與單位表) 時，題型換成以下四種，期中至少兩種、最終至少三種：

| 題型 | 考什麼 | 範例 (〈登高〉) |
|---|---|---|
| 字詞題 | 能否在語境中解釋字義，分辨古今異義 | 題目附上完整句子，問其中一個詞在句中的意思 |
| 句意題 | 能否用白話說出句意或段意 | 用你自己的話翻譯頷聯，並說出它寫的是什麼景 |
| 手法題 | 能否指出手法並說明效果 | 「萬里悲秋常作客」一句疊加了哪幾層悲，這樣寫有什麼效果 |
| 遷移題 | 能否把學到的手法用在沒讀過的文本 | 附一首沒講過的短詩，找出與本篇相同的手法 |

經典文本補充：

- 題目一律附上需要的原文，不讓使用者憑記憶作答。
- **受版權保護的作品** (教材中寫「原文請見課本」的單元) 不附原文，改用段號、行號指稱並附轉述。轉述要用自己的句法重新說出意思，不能只替換幾個字，也不能沿用原句的結構與意象順序。這條優先於「題目自帶推理所需的資料」，評分草稿提到原文時同樣只寫行號。
- 遷移題使用的文本必須是公共領域作品，且完整附在題目中。
- 以通行注本與課本的主流解讀為判對錯的依據。手法題與主旨類題目，評分看使用者有沒有引用文本證據；字詞題看語境理解，措辭寬鬆。

## 出題規則

- 每題聚焦一個節點 (或單位)。一題可以有兩三個小問，但小問都要服務同一個節點。
- **用詞與講解時的定義一致**，使用術語表的主名稱。例如講解中區分了「碳碳雙鍵」與羧基的 C=O，題目就寫「碳碳雙鍵」。
- **題目自帶推理所需的資料**：要考的是推理，就把分子式、數據、條件寫在題目裡；前後題目用到相似對象時，標明各自的名稱與資料，避免混淆。
- 題目中出現的新名詞 (例如新的分子名稱) 附上足夠資訊，讓使用者不需要額外知識也能作答。
- 優先考前次驗收中答錯的節點，以及備註「需補」「需再複習」的節點，確認補強有效。
- 節點內有比較表時，可以出辨析題考表中最容易混淆的兩項。
- 評分草稿中有 stolas-thread 判定深淺時替每段本體機制寫的考題，期中與最終驗收優先沿用或改寫成新情境，這些題目原本就設計成「只學會其他段的人答不出來」。
