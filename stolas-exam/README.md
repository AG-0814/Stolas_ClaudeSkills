# Stolas Exam：驗收 skill

Stolas Exam 是 Stolas 系列的驗收 skill，替 stolas-thread 的教材檔或 stolas-web 的主檔出題、批改、補測，並把結果寫回原檔。講過不等於學會，本 skill 用文字作答的題目確認使用者能用自己的話重建概念，作答證據是「已掌握」的唯一來源。

| 來源 | 考什麼 | 題型 |
|---|---|---|
| stolas-thread 教材 | 縱向的深度：機制、因果、應用 | 解釋、應用、辨析 (經典文本改用字詞、句意、手法、遷移) |
| stolas-web 主檔 | 橫向的關係：定位、辨析、串聯 | 定位、辨析、串聯、歸位，每題至少牽涉兩個關鍵字 |

## Stolas 系列

| 技能 | 起點 | 展開方式 |
|---|---|---|
| stolas-thread | 手上只有一個詞 | 一條線：AI 先排好脈絡地圖，縱向展開 |
| stolas-web | 手上可能有一張詞彙表 | 一張網：依使用者點名，攤成心智圖 |
| stolas-exam | 已有 thread 教材或 web 主檔 | 出題、批改、補測，結果寫回原檔 |
| stolas-print | 已結案的 thread 教材或 web 主檔 | 產出 PDF |

## 使用方式

訊息以 `/stolas-exam` (或全形 `／stolas-exam`) 開頭時啟動，後面可接檔名、主題或範圍，例如：

- `/stolas-exam`：考本對話中最近更新的教材或主檔
- `/stolas-exam 不飽和脂肪`：指定主題
- `/stolas-exam K3 這一支`：web 主檔只考某一支，以及與它有關聯的詞

在已經用過 stolas-thread 或 stolas-web 的對話中，說「驗收」「開始測驗」「考我」「跳至結尾驗收」也會啟動。

thread 教材依進度決定這一輪的範圍：

| 情況 | 這一輪 | 題數 |
|---|---|---|
| 還有待講解的節點 | 期中驗收：上次驗收後新講解的節點 | 2 到 3 題 |
| 全部講完 | 最終驗收：全部節點，加上先前未通過的補測 | 3 到 5 題 |
| 說「跳至結尾驗收」 | 最終驗收：全部節點，含尚未講解的 | 3 到 5 題 |

web 主檔每輪 3 到 5 題，至少要有 3 個已建立條目才會出題，〔待拆〕的詞不考。

批改後會停下等你消化回饋，接著可以這樣做：

| 說法 | 作用 |
|---|---|
| 補測 | 針對未掌握的部分，換一個新情境再考一題 |
| 結束驗收 | 結束這一輪，未作答的題目標「未作答」 |
| 直接追問 | 針對回饋內容提問 |

## 寫回的內容

- **thread 教材**：節點表的狀態改為「已掌握」，或在備註加「建議複習」「需再複習」；「驗收」章節記下每輪的題目、評級與回饋；未掌握而補講的內容整併進對應節點。不寫一頁重點、不結案、不產 PDF。
- **web 主檔**：只寫「驗收紀錄」章節，條目與目錄樹不加掌握標記，維持速查表的克制。回饋中修正了某個詞的位置或白話版時，會同步更新條目與心智圖。

舊版 stolas 的教材與 stolas-lite 的主檔也認得。

## 檔案結構

```
stolas-exam/
├── SKILL.md                     流程：找材料、定範圍、出題、批改、寫回
├── README.md                    本說明
├── LICENSE                      授權條款
└── references/
    ├── thread-exam.md           thread 教材的題型與出題規則
    ├── web-exam.md              web 主檔的題型與出題規則
    └── grading.md               跨題檢查、評分、回饋與補測 (兩種模式共用)
```

## 環境需求

- 需要開啟程式執行 (Code Execution) 功能，才能讀取與寫回教材檔或主檔。
- 評分草稿存在隱藏檔 `.stolas-<slug>-rubric.md`，與 stolas-thread 共用。
