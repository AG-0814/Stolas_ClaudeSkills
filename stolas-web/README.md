# Stolas Web：把一堆詞攤成一張網的速查 skill

Stolas Web 是一個 Claude skill，適用於使用者手上有一張詞彙表，或讀資料時一路撞見一堆專有名詞的情況。它圍繞一個大主題 (一個產業、一項政策、一個技術領域，或某份計畫、報告的標題)，依使用者點名逐一拆解子名詞，講解以非專業人員也看得懂為基準，並把詞與詞之間的從屬、對比、因果攤成目錄樹與 Mermaid 心智圖。所有條目累積寫入同一份 Markdown 主檔，附 Obsidian 可讀取的學科標籤。驗收另由 stolas-exam 進行，PDF 另由 stolas-print 產出。

## Stolas 系列

| 技能 | 起點 | 展開方式 |
|---|---|---|
| stolas-thread | 手上只有一個詞 | 一條線：AI 先排好脈絡地圖，縱向展開 |
| stolas-web | 手上可能有一張詞彙表 | 一張網：依使用者點名，攤成心智圖 |
| stolas-exam | 已有 thread 教材或 web 主檔 | 出題、批改、補測，結果寫回原檔 |
| stolas-print | 已結案的 thread 教材或 web 主檔 | 產出 PDF |

## 使用方式

訊息以 `/stolas-web` (或全形 `／stolas-web`) 開頭，後面接大主題名稱才會啟動，可另附相關文件或詞彙表，例如：

- `/stolas-web 智慧電網`
- `/stolas-web 半導體先進封裝`
- `/stolas-web 殖利率` (單一術語時，以它所屬的領域當主題，並直接拆解這個詞)

開場後直接丟關鍵字，一次一個或貼一整串都可以。同一則訊息裡的詞依狀態分三種處理：

| 詞的狀態 | 處理 |
|---|---|
| 你在問的詞 | 在聊天中完整拆解，主檔只收精簡條目 |
| 你已用自己的話說明理解 | 確認沒錯就直接寫入，條目標註「依你的說法整理」 |
| 只是順帶提到，或在清單裡 | 登記編號，在目錄樹與心智圖標〔待拆〕，之後再拆 |

拆解過程中可以使用以下說法：

| 說法 | 作用 |
|---|---|
| X 下的 Y、Y 跟 X 比 | 標出新詞與既有詞的從屬或對比關係 |
| 做個比較表、畫圖、換個比喻 | 追問已拆的詞，產生的表、圖、比喻會收錄到條目下 |
| 看目錄樹 | 在聊天中列出目前整張網，不修改主檔 |
| `/stolas-exam` 或「考我」 | 驗收詞與詞之間的關係 (由 stolas-exam 進行) |
| `/stolas-print` 或「產出 PDF」 | 產出主檔當下的 PDF 速查 (由 stolas-print 進行) |

要拆哪些詞、往哪個方向深入，完全由使用者決定，skill 不會主動推薦下一個詞。想深入某個詞時，建議另開 `/stolas-thread 該詞`。

## 主檔內容

主檔檔名為 `stolas-web-<主題>-<日期>.md`，依序包含：

- **主題背景卡**：主題的白話定義與涵蓋面向
- **目錄樹**與 **Mermaid 心智圖**：整張網的結構，〔待拆〕的詞也會列出
- **關鍵字條目**：每個詞三行 (位置、一句話白話版、在本主題中的角色)，加上追問中收錄的比較表與比喻
- **驗收紀錄**：由 stolas-exam 寫入
- **資料來源**

## 檔案結構

```
stolas-web/
├── SKILL.md                     主流程、拆解規則、主檔模板與學科分類
├── README.md                    本說明
└── LICENSE                      授權條款
```

## 環境需求

- 需要開啟程式執行 (Code Execution) 功能，主檔才能產生。沒有檔案工具時，主檔改以 Markdown 貼在聊天中。
- 名詞的通用解釋需要查證時會搜尋，但不主動搜尋主題本身的特定外部資訊 (例如某機關公告、相關新聞)，避免帶入使用者沒給的前提。
