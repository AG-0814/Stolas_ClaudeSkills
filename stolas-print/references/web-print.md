# web 主檔的 PDF 流程

SKILL.md 判定為 web 模式時讀取。

## 執行

```
python scripts/build_web_pdf.py <主檔.md> <輸出.pdf>
```

腳本直接讀主檔，不需要先產印刷版 Markdown，也不需要手動填版面。同時會在輸出 PDF 旁留一份同名 HTML (排版結果)。

## 版面規則 (腳本已實作，供檢查與說明用)

**第 1 頁封面**，固定一頁，依優先順序填入：

1. 標頭：主題名稱、原文 (取自背景卡第一句括號中的英文)、學科與日期、**主題背景卡的第一句**。
2. 關鍵字地圖：主檔「心智圖」章節的 Mermaid 原始碼，去掉標了〔待拆〕的行後渲染。
3. 比較表一張：主檔有收錄比較表時才放，挑法見下方。
4. 每個詞一句話：封面放得下才放。

腳本會實際排版量高度，放不下時把「每個詞一句話」移到下一頁；連比較表也放不下時，比較表移到一句話之後另起一頁。封面底部固定一行統計：關鍵字數、比較表數、資料來源數。

**第 2 頁起**，依序流動：

- 每個詞一句話：依主檔條目順序，兩欄排列，一句話白話版原文照用，不刪減、不改寫。待拆的詞沒有條目，不會出現。
- 資料來源：主檔有才放，全部列出。8 筆以上另起一頁，少於 8 筆時接在前一節後面。
- 單一條目、表格列、章節標題都不跨頁切斷，標題一定和下方內容在同一頁。

**比較表的挑法**：數每張表的表頭與第一欄中，恰好是主檔關鍵字主名稱的格數，取最多的一張；平手時取列數多的。表下方註明它收錄在哪個關鍵字條目。

**配色**：讀 frontmatter 的學科標籤 (`學科/大類/學群/小分類`)，取學群套用 `assets/palette.json` 的 ink 與 soft 色；沒有學科標籤的舊主檔用預設配色。

**不收的內容**：驗收紀錄、比喻、其餘比較表。內容只取自主檔，不補寫主檔中沒有的文字。

## 降級

| 情況 | 處理 |
|---|---|
| 沒有 mermaid-cli，或心智圖轉換失敗 | 封面改放主檔的文字版目錄樹 (同樣去掉待拆) |
| 主檔沒有比較表 | 封面只放心智圖，放得下時接著放每個詞一句話 |
| 沒有 Playwright | 腳本只輸出 HTML 並以代碼 3 結束，交付 HTML，告知使用者用瀏覽器「列印 → 另存為 PDF」 |

## 檢查重點

看封面預覽時確認三件事：心智圖節點文字清楚可讀、比較表沒有被擠壓到一格一兩個字、統計列的數字與主檔相符。心智圖節點過多導致文字太小 (大約 25 個詞以上) 時，在交付時用一句話說明，建議使用者對照內頁的一句話閱讀。
