# thread 教材的 PDF 流程

SKILL.md 判定為 thread 模式時讀取。教材是工作底稿，圖片只以「繪圖規格」記錄；PDF 是給之後回顧用的筆記，圖片在這一步才併入，學習過程的紀錄壓縮到附錄。

## 步驟

1. 若環境中有 PDF 相關的 skill，先讀取它的說明，了解環境限制。
2. **重繪圖片**：依教材「圖解」章節每張圖的繪圖規格，一次批次繪製成 SVG 檔 (規範見 `visual-toolkit.md`)。學習過程中已存成 SVG 檔的圖 (內容欄註明了檔名) 直接沿用。
3. **製作一頁重點**：複製 `assets/onepage-a4.html` 為 `stolas-thread-<slug>-onepage.html`，依檔內註解把【】佔位文字換成本單元的內容，主要素材是教材的「一頁重點」章節 (stolas-thread 結案時寫入)。是否放圖片、放示意圖還是真實圖片，依下方「一頁重點的圖片」判斷。只改文字與可增刪的區塊，CSS 保持原樣；字數上限寫在各區塊的註解中。
4. **產生印刷版 Markdown**：依下方「印刷版」結構，從教材複製並調整：圖片插入到對應節點小節中，提問紀錄 (與驗收紀錄，有的話) 壓縮成附錄，刪除版本紀錄。
5. **轉檔**：執行 `scripts/build_pdf.py 印刷版.md 輸出.pdf --onepage stolas-thread-<slug>-onepage.html --category <學群> --depth <淺|中|深>`。學群取 frontmatter 主標籤的學群名稱 (例如 `學科/社會商管/財經/賽局理論` 取 `財經`)，深淺取教材脈絡地圖判定行的淺題、中等、深題 (經典文本單元一律用 `中`)。腳本依此套用一頁重點的配色，文字黑白自動依對比度切換。腳本會先檢查一頁重點沒有超出頁面、沒有殘留佔位文字，通過後放在 PDF 第一頁；接著把 Mermaid 圖轉成圖、公式轉成可列印格式、使用中文字型，並在缺工具時自動降級。
   - 腳本以代碼 2 結束時，依它列出的問題刪減一頁重點的文字 (優先縮短說明句，其次減少要點數量)，再重跑，最多三次。
   - 三次仍不通過，或環境無法渲染 (例如沒有 Playwright)，改用不帶 `--onepage` 的指令轉檔，印刷版保留文字版一頁重點，並在交付時用一句話說明。
6. **檢查**：把 PDF 的第 1 頁 (一頁重點) 與任一張含圖的頁面轉成預覽圖看一眼，確認中文、公式、圖片都正常，再交付。
7. **交付**：檔名 `stolas-thread-<slug>-<YYYY-MM-DD>.pdf`，日期取產出當天，放在教材同一個資料夾，與最終版 Markdown 一起呈現。
8. 轉檔全部失敗時，改交付 HTML 版本，並告知使用者可用瀏覽器的「列印 → 另存為 PDF」自行轉檔。

## 一頁重點的圖片

一頁重點的「01 核心機制圖」或其中一張重點卡，可以換成一張圖。換之前確認三件事都成立：

1. 圖呈現的是結構、空間或流程，用文字至少要兩句以上才講得清楚。
2. 縮小到區塊大小仍看得清楚，標籤大約 6 個以內。
3. 圖的資訊沒有和其他區塊重複。

再決定用哪一種圖：

- **讀者需要「認得它長什麼樣」** (古建築構件、颱風路徑、實體物件)：用真實圖片。來源限公有領域或 CC 授權 (維基共享資源、美國政府機構如 NOAA、博物館開放資料)，在頁尾註明出處、作者與授權。不使用宣傳照、新聞照、圖庫素材；人物只用公有領域的歷史肖像。環境無法下載圖片時，改用示意圖。
- **讀者需要「看懂它怎麼運作」** (晶片堆疊、分子結構、因果流程)：用示意圖，優先沿用學習過程中已經畫過的那張。

## 印刷版

印刷版是給之後回顧用的筆記，正文只放理解內容，學習過程壓縮到附錄。依序：

1. 標頭表格與一頁重點。一頁重點已用 `assets/onepage-a4.html` 做成 PDF 第一頁時，印刷版刪除文字版的「一頁重點」章節，只保留標頭表格；一頁重點版面製作失敗時才保留文字版。
2. 起點問題 (若有)、一句話定義、脈絡地圖 (判定行、心智圖與節點表，表格只保留編號、節點、欄位、備註)。
3. 節點講解：每張圖以 `![圖 N：說明](檔名.svg)` 插入到所屬節點小節中、最相關段落之後。
4. 操作步驟 (若有)、常見誤解、術語表。
5. 附錄 A：學習紀錄。學前診斷寫一兩句落點；提問紀錄原樣保留 (它是使用者的思路軌跡)。教材「驗收」章節有 stolas-exam 的紀錄時，每題壓縮成一列「題目摘要、評級、回饋重點」並附跨題模式；沒有驗收紀錄時省略這部分，不寫「未驗收」。
6. 附錄 B：資料來源。

刪除：起步站點、圖解章節的規格表 (圖已插入正文)、版本紀錄、教材版本行。
