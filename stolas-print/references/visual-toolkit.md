# 依繪圖規格重繪 SVG

thread 模式步驟 2 讀取。學習過程中，stolas-thread 只在聊天中畫圖，教材「圖解」章節記下每張圖的繪圖規格；本技能依規格一次重繪成 SVG 檔，插入印刷版。

## 讀規格

「圖解」表格每列一張圖：

| 欄 | 用途 |
|---|---|
| 圖 | 編號，印刷版中寫成「圖 N：說明」 |
| 所屬節點 | 圖要插入的節點小節 |
| 內容 | 一句話說明；註明了檔名 (例如 `fig-2.svg`) 時，表示學習中已存成檔案，直接沿用，不重繪 |
| 繪圖規格 | 類型與佈局、每個元素與標籤、強調方式、圖說 |
| 看圖重點 | 寫在印刷版圖片下方的說明 |

規格寫得不夠完整時，依所屬節點小節的講解補足細節，不加入講解中沒有的內容。

## 手寫 SVG 規範

- 使用 `viewBox`，寬度 680 左右，不寫死像素寬高。
- 最底層放白色背景矩形，並用內嵌 `<style>` 定義顏色。
- 中文標籤字級至少 12。
- 顏色之外，同時用線型或文字標籤區分重要元素。
- 存檔前用 Python 或 `xmllint` 檢查是否為合法 XML。
- 檔名 `stolas-thread-<slug>-fig<N>.svg`，與印刷版 Markdown 放在同一個資料夾，印刷版以相對路徑引用。

## 各工具注意事項

- **RDKit** (分子結構)：`pip install rdkit --break-system-packages` 失敗即改手寫 SVG，不重試。
- **matplotlib**：沙盒中常缺中文字型，圖內標籤優先用英文。
- **Mermaid**：規格本身是流程或層級時，可以直接在印刷版寫 Mermaid 區塊，`build_pdf.py` 會轉成圖。節點文字不能有半形括號 `()` `[]` `{}`。
